# tokensView

Приложение для Windows, которое показывает, сколько токенов расходует Claude Code и сколько это стоило бы по ценам API.

- расход по сессиям, проектам, часам, дням, неделям и месяцам с графиками;
- стоимость по актуальным ценам Anthropic API, с учётом кэша;
- сравнение подписки Claude со стоимостью тех же запросов по API и прогноз на месяц;
- значок в трее и компактный виджет, который можно закрепить поверх окон.

## Установка

Скачайте `tokensView-Setup-*.exe` из последнего релиза в разделе [Releases](https://github.com/YANGROK-lab/tokensView-releases/releases/latest) и запустите его. Дальше программа обновляется сама.

Программа не подписана сертификатом, поэтому при первом запуске Windows может показать «Windows защитила ваш компьютер». Нажмите **Подробнее → Выполнить в любом случае**.

## Подписка

Первые 14 дней все функции бесплатны. Потом подписка стоит **$1 в месяц**: напишите в Telegram [@fpacchub](https://t.me/fpacchub), и после оплаты вы получите ключ. Ключ вводится в **Настройки → Лицензия**.

Без подписки остаются сессии, проекты и периоды за последние 30 дней, а также значок в трее. По подписке доступны виджет поверх окон, сравнение с подпиской Claude и вся история.

## Приватность

Программа читает только локальные логи Claude Code (`%USERPROFILE%\.claude\projects`) и никуда их не отправляет. В интернет она обращается только за обновлениями на GitHub.
